# External RTOS dependency

This coursework uses Micrium uC/OS-II 2.86 and an STM32F103 board support package. Obtain uC/OS-II from an authorized source under its applicable terms and place the kernel at the paths referenced by the Keil project. The kernel implementation is not redistributed here. Board-support file notices are preserved. Other sample applications are retained as teaching/reference context, not presented as separately authored projects.
